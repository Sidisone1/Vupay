# Vupay — architecture responsive site web + application

Vupay doit être accessible comme site web responsive sur téléphone, tablette et ordinateur, avec installation PWA pour les diffuseurs et annonceurs. L'administration web garde des vues de contrôle adaptées au grand écran.

- Diffuseur : campagnes, liens traçables, clics, gains et retraits.
- Annonceur : création de campagne, budget et rapports.
- Administration : validation, fraude, paiements et paramètres.

Téléphone : partage et suivi rapide. Tablette : campagnes et statistiques en panneaux. Ordinateur : tableaux de bord, analyse des clics et gestion des campagnes. Les paiements, retraits et statistiques doivent être confirmés par les intégrations réelles.

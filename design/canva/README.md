# Vupay — 48 maquettes sur Canva

- **Éditer les 48 écrans :** https://www.canva.com/d/JFygNqJaw1LNavO
- **Format :** mobile 390 × 844 pixels.
- **Écrans :** accueil, inscription, choix de rôle, diffuseur, campagnes, gains, retrait, annonceur, visiteur, admin, erreurs, sécurité et paramètres.
- **Identité validée :** vert profond, vert vif, crème, orange/ocre, brun et pictogrammes Bogolan.
- **Source des icônes déjà conservées dans GitHub :** `apps/web/public/icones/` et `design/icones/`.
- **Charte cible :** `design/charte/BOGOLAN_VERT_V4.md`.
- **Fonctionnement cible :** `docs/PRODUIT_V2_CLICS_QUALIFIES.md`.

## Important
La maquette Canva est **une source de design externe**, pas un dossier de 48 images synchronisées automatiquement avec GitHub. Les anciennes images PNG des maquettes sont déjà dans `design/maquettes/`. Pour archiver chaque nouvel écran Canva dans Git, l'export PNG/SVG doit être effectué puis ajouté avec un nom stable.

## Nommage futur des exports
`design/canva/exports/v4/01-accueil.png`, `02-role.png`, etc. Ne pas remplacer les maquettes V3 sans revue et validation.

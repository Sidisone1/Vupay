# Site web et application sur 3 appareils

Maquette interactive de Vupay : le **site public** et l'**application du diffuseur** (Accueil, Campagnes, Gains, Retraits, Profil), mis en page pour **téléphone (390 px)**, **tablette (820 px)** et **ordinateur (1280 px)** avec des container queries.

- Ouvrir `index.html` dans un navigateur : boutons *Site web / Application* et *Téléphone / Tablette / Ordinateur / Les trois*.
- Tout se clique : onglets et menu latéral changent d'écran sur les trois appareils, les boutons affichent un message de démonstration, les filtres se sélectionnent.
- Charte V4 : vert #006B3A, vert vif #14AA4D, orange #F08300, brun #884A1F, crème #FFF7E6, texte #092E1B ; Poppins (titres) et Inter (interface).
- Icônes : les 28 icônes Bogolan V4 utilisées sont copiées dans `icones/`.
- Concept V2 : seuls les clics qualifiés sont comptés (appel, message WhatsApp, catalogue, achat), jamais les vues.
- **Montants d'exemple** : les tarifs ne sont pas définis et les paiements ne sont pas actifs.

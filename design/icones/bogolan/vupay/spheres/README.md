# Icônes Vupay V4 en sphères

`index.html` imprime les 32 icônes de `../png/` sur des sphères en caoutchouc brillant : composant **Rubber Spheres**
d'OriginKit (https://www.originkit.dev/components/rubber-spheres), three.js 0.170.0 et React 18.3.1 compilés dans
`spheres.js`. À ouvrir via un petit serveur (`python3 -m http.server`), pas en `file://`.

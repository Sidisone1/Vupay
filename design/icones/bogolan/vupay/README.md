# Icônes 3D Bogolan — Vupay

32 icônes 3D dans le style « Collection Bogolan », aux couleurs de la **charte V4 validée** (`design/charte/BOGOLAN_VERT_V4.md`) :
vert profond #006B3A, vert vif #14AA4D, ocre #F08300, brun #884A1F, crème #FFF7E6, texture argile, avec une bande bogolan brune (#884A1F). Aucune couleur ni logo de réseau social
ou de WhatsPay. Proposition **à valider**.

| Dossier | Contenu |
| --- | --- |
| `planches/` | `vupay-v4-01.png` et `vupay-v4-02.png` (sources actuelles, V4) ; `vupay-vert-*` (v3) et `vupay-indigo-*` (v2) gardées pour l'historique |
| `png/` | 32 icônes découpées, PNG 256 × 256, coins arrondis, fond transparent |
| `scripts/icones_vupay.json` | Liste : nom de fichier et libellé français |
| `scripts/prompt_vupay.py` | Consigne de génération d'une planche |
| `scripts/decouper_vupay.py` | Découpage d'une planche en icônes |

- **Planche 1 (espace diffuseur)** : campagnes, gains, retrait, profil, accepter, publier, preuve, encaisser, cadenas, info,
  chrono, accueil, telecharger, selfie, piece-identite, mobile-money.
- **Planche 2 (annonceur et admin)** : tableau-de-bord, nouvelle-campagne, portefeuille, factures, entreprise, preuves,
  identites, moderation, retraits, utilisateurs, parametres, journal, recherche, audience, vues, fraude.

Les 5 onglets de la charte V4 sont couverts : accueil, campagnes, gains, retraits (retrait), profil.
Ces icônes ne remplacent pas encore celles de l'application (`apps/web/public/icones/`) : à valider d'abord.

Les montants affichés sur les icônes sont en FCFA (Gains, Retrait, Portefeuille, Factures, Mobile Money).

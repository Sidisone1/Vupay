# Icônes 3D Bogolan — Vupay

32 icônes 3D dans le style « Collection Bogolan », aux couleurs de Vupay (charte v2) : indigo #3533B8, safran #F6A609,
corail #EE5A3B, encre #15162B, blanc, avec une bande bogolan brun terre (#6B3E26). Aucune couleur ni logo de réseau social
ou de WhatsPay. Proposition **à valider**.

| Dossier | Contenu |
| --- | --- |
| `planches/` | 2 planches sources de 16 icônes (1024 × 1024) |
| `png/` | 32 icônes découpées, PNG 256 × 256, coins arrondis, fond transparent |
| `scripts/icones_vupay.json` | Liste : nom de fichier et libellé français |
| `scripts/prompt_vupay.py` | Consigne de génération d'une planche |
| `scripts/decouper_vupay.py` | Découpage d'une planche en icônes |

- **Planche 1 (espace diffuseur)** : campagnes, gains, retrait, profil, accepter, publier, preuve, encaisser, cadenas, info,
  chrono, copier, telecharger, selfie, piece-identite, mobile-money.
- **Planche 2 (annonceur et admin)** : tableau-de-bord, nouvelle-campagne, portefeuille, factures, entreprise, preuves,
  identites, moderation, retraits, utilisateurs, parametres, journal, recherche, audience, vues, fraude.

Aperçu en situation : `design/maquettes/maquettes-bogolan.html` (les 22 écrans avec ces icônes dans la barre d'onglets,
les menus latéraux, les étapes de l'accueil et les encarts). Les maquettes d'origine (`diffuseur/`, `annonceur/`, `admin/`)
ne sont pas modifiées. Générées le 17/11/2026 avec Figma AI.

À vérifier : l'icône « Factures » porte un symbole « $ » (à refaire en FCFA si besoin).
